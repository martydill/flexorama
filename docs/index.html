Everything you need

Powerful features for both CLI and web workflows

🖥️

Hybrid Interface

Use the CLI for terminal workflows or launch the web UI for a ChatGPT-style experience with chats, plans, agents, and MCP management.

🔌

MCP Support

Full Model Context Protocol support for connecting to external tools, data sources, and services.

🔍

Context Management

Add files with @path syntax, search conversations, and maintain session history in SQLite.

🎯

Tools & Skills

Built-in file editing, bash, code search, glob tools, plus Claude-style skills support.

💬

Slash Commands

Custom commands via ~/.flexorama/commands/, autocomplete, and command history.

🤖

Subagent Support

Spawn specialized subagents via /agent for complex multi-step tasks.

🔎

Conversation Search

Full-text search across all conversations with /search to find past discussions.

🔄

Session Resume

Pick up where you left off with /resume to continue previous conversations.

📊

Plan Mode

Create and manage plans with /plan command for structured project planning.

🎨

Syntax Highlighting

Beautiful code snippet formatting with proper syntax highlighting.

🔗

Hooks Support

Limited Claude Code-style hooks (UserPromptSubmit, PreToolUse, PostToolUse, Stop, SubagentStop).

📁

Multi-File Context

Read multiple files at once with multi_read_files for efficient context loading.

🎛️

System Prompts

Set custom system prompts with -s flag to control AI behavior and personality.

⏹️

Conversation Cancellation

Press ESC during AI processing to immediately cancel ongoing conversations.

Works with your favorite LLM providers

Switch providers with --provider flag

Anthropic Claude OpenAI GPT Google Gemini Mistral Z.AI Ollama (Local)

Get Started

Install Flexorama and start coding smarter

With Cargo

cargo install flexorama

Set your API key

export ANTHROPIC_AUTH_TOKEN="your-api-key"
# Or use --api-key flag

Run it

# CLI mode
flx -m "Help me write a function"

# Web UI mode
flx --web

# With custom provider
flx --provider openai -m "Your message"
